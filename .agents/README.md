# Контур Codex -> Gemini -> Codex

1. Codex создаёт спецификацию/архитектуру и одно ограниченное задание в
   `.agents/tasks/`.
2. Владелец пишет Gemini в Antigravity: «Прочитай `.agents/AGENTS.md` и выполни
   `.agents/tasks/NNN-name.md`».
3. Gemini меняет код, тестирует и создаёт `.agents/reports/NNN-name.md`.
4. Владелец сообщает Codex, что отчёт готов.
5. Codex читает diff и отчёт, сам повторяет тесты, при необходимости создаёт
   корректирующее задание, а результат ревью сохраняет в `.agents/reviews/`.

Задание должно быть достаточно небольшим, чтобы один исполнитель мог закончить
и доказательно проверить его за один цикл. Архитектурные этапы нельзя склеивать
в одну команду «сделай всё».

Текущая готовая задача: `001-refresh-layer-scan.md`.
