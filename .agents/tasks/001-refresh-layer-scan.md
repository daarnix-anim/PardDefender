# Задача 001: ручное обновление сканирования забытых слоёв

Статус: ready

## Контекст

Пользователь вручную исправляет или удаляет найденные выключенные/забытые слои
и композиции в After Effects. Сейчас панель обновляет список только по общему
`scanIntervalMs`, поэтому после ручной чистки показывает устаревшие строки.

Baseline на момент постановки задачи: `node tests/run-all.js` проходит; итоги
172 host + 50 copy-queue + 112 runtime + 116 panel. В рабочем дереве уже есть
значительные незакоммиченные изменения владельца — сохранить их.

## Результат

В секции `ВЫКЛЮЧЕННЫЕ СЛОИ` есть компактная кнопка обновления. Она немедленно
повторяет существующее сканирование и показывает фактическое состояние проекта,
не ожидая таймера аудита.

## UX-контракт

- Компактный control расположен в заголовке секции.
- `title`/доступное имя: `Обновить список`.
- Нажатие немедленно вызывает существующий путь `scanLayersToFile()` независимо
  от `scanIntervalMs` и общего аудита.
- Во время запроса повторный запуск запрещён; виден неблокирующий busy-state.
- Успех заменяет `state.layers`, обновляет секцию и вкладки и записывает
  `lastLayerScanAt`, чтобы таймер не дублировал только что законченный проход.
- Если находок не осталось, секция скрывается штатным способом.
- Ошибка сохраняет последний успешный список, пишет короткое предупреждение в
  существующий журнал и снова разрешает кнопку.
- Ручной и автоматический запуск используют один guarded code path. Устаревший
  callback не должен перезаписать более новый результат.
- Неизменившийся результат не сбрасывает scroll и не делает лишний
  `innerHTML`-rewrite списка.

## Обязательные тесты

Расширь panel harness и докажи:

1. у кнопки есть обработчик;
2. нажатие запускает новый scan, даже если интервал ещё не истёк;
3. изменённый mocked layer report немедленно обновляет или скрывает секцию;
4. повторное нажатие при pending callback не запускает параллельный scan;
5. ошибка оставляет прежние findings и позволяет retry;
6. неизменившийся refresh не создаёт лишних записей `innerHTML`.

Затем запусти `node tests/run-all.js`, `git diff --check` и создай отчёт
`.agents/reports/001-refresh-layer-scan.md` по шаблону.
