## Решения и отклонения

- Переключатели — состояние сессии, не настройки проекта. Нет изменений схем
  хранимых метаданных, версий, маршрутов защиты, manifest id или release-архивов.
- Фильтр 3D-слоёв использует layer.threeDLayer; 3D-модели — отдельная категория.
- Photoshop/vector показываются как изображения; композиции включают pre-comp.
- Фильтр меняет только список. Кнопка защиты продолжает обрабатывать весь audit;
  простое переключение вида не публикует snapshot.
- Проверены актуальные официальные
  [ProjectUtils](https://developer.adobe.com/premiere-pro/uxp/ppro-reference/classes/projectutils)
  и [типы Adobe](https://github.com/adobe/premierepro-types/blob/main/src/premierepro.d.ts).
  Есть getSelection/getSelectionFromViewId, но нет API выделения в Project view,
  Reveal in Project или executeCommand. Не использованы QE, CEP и эмуляция клавиатуры.

## Ручная проверка

1. Перезапустить After Effects и Premiere для загрузки нового runtime.
2. AE: открыть «Выключено и забыто», менять высоту/ширину dock. Строки не должны
   сжиматься; список прокручивается и использует свободную высоту.
3. Выбрать композиции, видео, изображения, аудио, 3D-модели, 3D-слои. Проверить
   пустой результат и возврат «Все типы», группировку по композиции/типу.
4. Проверить открытие слоя/композиции, пометку забытым, исключение с комментарием.
5. Premiere: переключить тип, формат, папку, имя. Проверить роли аудио и «AE защита».
6. С активным фильтром защищать внешние: скрытые элементы должны тоже получить
   защищённый путь. Оригиналы не удалять до проверки сохранённого проекта.
