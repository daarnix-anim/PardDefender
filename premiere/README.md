# PardDefender для Adobe Premiere Pro (UXP)

Отдельный плагин нового поколения для Adobe Premiere Pro на базе официальной архитектуры
Adobe UXP (Unified Extensibility Platform), manifestVersion 5.

## Требования

- **Adobe Premiere Pro:** версия 25.6 или выше.
- **Архитектура:** UXP manifestVersion 5.
- **Запрещённые технологии:** QE DOM, ExtendScript, CEP, `evalScript`, прямое редактирование закрытых `.prproj` файлов не используются.

## Разрешения (Permissions)

В `manifest.json` запрошено разрешение:
```json
"requiredPermissions": {
  "localFileSystem": "fullAccess",
  "clipboard": "readAndWrite"
}
```

### Почему `fullAccess`?
В отличие от веб-приложений, пользовательские видеопроекты Premiere Pro и исходные медиафайлы
могут находиться в произвольных директориях локальных накопителей и сетевых хранилищ.
UXP требует `fullAccess` для чтения и организации медиа рядом с открытым файлом проекта.

**Гарантия безопасности:** PardDefender строго ограничивает любые операции рамками
разрешённой рабочей папки проекта (`workspaceRoot`), определяемой по расположению
активного `.prproj`. Никакие файлы за пределами рабочей папки проекта не модифицируются.

## Установка и запуск в режиме разработки (Dev Load)

### Способ 1: Через Adobe UXP Developer Tool (UDT) (Рекомендуется)
1. Установите и запустите официальный **Adobe UXP Developer Tool** из Creative Cloud Desktop.
2. Нажмите **Add Plugin** и выберите файл `premiere/com.pard.defender.uxp/manifest.json`.
3. Запустите Adobe Premiere Pro (версия 25.6+).
4. В UDT в строке плагина выберите **Actions -> Load**.
5. В Premiere Pro откройте панель через меню: **Окно (Window) -> Расширения (Extensions) -> PardDefender** (или **Plugins -> PardDefender**).

### Способ 2: Прямое размещение в папке плагинов UXP
Скопируйте папку `com.pard.defender.uxp` в директорию плагинов UXP вашей системы:
- **Windows:** `%APPDATA%\Adobe\UXP\Plugins\com.pard.defender.uxp`
- **macOS:** `~/Library/Application Support/Adobe/UXP/Plugins/com.pard.defender.uxp`

## Возможности плагина

- **Интерфейс панели:** три вкладки («ЗАЩИТА», «ДУБЛИКАТЫ», «ЖУРНАЛ»).
- **Официальный UXP-адаптер (`adapter.js`):**
  - Определение активного проекта, GUID, пути и рабочей папки;
  - Корректная обработка несохранённых проектов;
  - Рекурсивный сбор медиафайлов по структуре папок (bins);
  - Извлечение путей исходников (`ClipProjectItem.getMediaFilePath()`);
  - Распознавание proxy (`hasProxy()`, `getProxyPath()`);
  - Классификация элементов: клипы, секвенции, multicam, merged, offline, generated (титры, подложки, настроечные слои);
  - Интеграция с реестром проектов `.parddefender/projects.json` с сохранением стабильного GUID при «Сохранить как».
- **Защита медиафайлов (`copy-engine.js`):**
  - Кнопка «ЗАЩИТИТЬ СЕЙЧАС» копирует внешние медиафайлы в `01_assets/_SHARED/VIDEO` рабочей папки проекта;
  - Асинхронное поблочное копирование с инкрементальным SHA-256 (NIST векторы);
  - Временные файлы `.pdpart`, валидация размера и контрольной суммы до атомарного rename;
  - Журналирование до записи (`pending.tsv`) и аварийное восстановление;
  - Фиксация provenance в `.parddefender/assets.tsv`;
  - Перелинковка через `ClipProjectItem.changeMediaFilePath(newPath, false)` с проверкой `canChangeMediaPath()` и post-relink verification.
- **Поиск дубликатов и консолидация (`duplicates.js`):**
  - Поиск 100% побайтовых копий с группировкой по SHA-256;
  - Рекомендация каноникала и возможность ручного переопределения;
  - Кнопка «ОБЪЕДИНИТЬ В ОДИН ФАЙЛ» с двухкликовым подтверждением (6 секунд окно защиты);
  - Re-verification хэша каноникала (`REHASH_MISMATCH` блокирует операцию);
  - Копирование внешнего каноникала в проект с фиксацией в `assets.tsv` до перелинковки;
  - Строгая гарантия безопасности: исходные файлы на диске НЕ удаляются, проектные элементы НЕ удаляются.

## Отличия от After Effects версии

1. **Нет сканирования забытых слоёв:** в Premiere Pro нет концепции скрытых/забытых слоёв («выключено и забыто»), так как структура таймлайна и клипов в bin отличается от композиций After Effects.
2. **Нет композиционной раскладки:** папки проекта (bins) в Premiere Pro отражают монтажную структуру пользователя и не форматируются по иерархии рендерных композиций.
3. **Асинхронная UXP-модель:** все вызовы к хосту выполняются через официальный объектный DOM UXP, без вызовов синхронного ExtendScript.
